# Captured knowledge

Structured interviews with the maintainer, captured as citable sources. Every research track and phase opens with a POV interview (see CLAUDE.md working protocol); production war stories get dedicated case-study interviews detailed enough to reconstruct the mechanism and the economics.

Files are named `interview-NN-topic.md` and contain the questions, the answers (in the maintainer's words, lightly edited), and the date. Findings cite them like any other source.
