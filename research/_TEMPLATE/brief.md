## The 13 standard questions, applied to this layer

1. Current state: what does a typical enterprise run today at this layer (per archetype)?
2. What changes with agents: agent as consumer of the layer, agents embedded in the layer, layer rebuilt for agents?
3. Introduction options and sequencing: buy embedded vendor agents, build on a platform, hybrid; prerequisites
4. Economics: who pays for the loop; pricing regimes at this layer (seat, agent-seat, metered); cost drivers
5. Learning: where does learning live (instance memory vs system flywheel); who defines evals; feedback capture
6. Risk and groundedness: failure modes, blast radius, grounding requirements, human checkpoints
7. Security and determinism: how access control stays deterministic while behavior is probabilistic; identity level required
8. Sovereignty: which actions at this layer are residency or jurisdiction events; classification and routing
9. Vendor landscape: real offerings vs agent-washing; lock-in surfaces (especially memory)
10. Target state: this layer inside the agentic enterprise; interop standards
11. Migration path: current to target; readiness signals; what to stop buying
12. Metrics: KPIs proving this layer's agentification is working
13. Data readiness and curation: what data this layer contributes to agent grounding and memory, what pre-processing and curation it needs per use case, and the token-economics impact
