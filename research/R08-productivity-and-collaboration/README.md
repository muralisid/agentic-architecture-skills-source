# R08: Productivity & collaboration

Status: complete (published 2026-08-19). Scope finalized at Batch D kickoff with maintainer POV; see brief.md, findings.md, vendors.md, sources.md.

## Scope inventory (v0)

- **Estate**: M365/Google Workspace, Slack/Teams, knowledge bases (SharePoint, Confluence), the meeting stack
- **Presence agents**: mailboxes, calendars, meeting participation, directory entries with managers, channel and workspace membership as the security boundary
- **Teaming design**: notification and attention design (avoiding agent spam), approval and escalation in the flow of work, agent etiquette and norms, personal vs team vs department agent scoping
- **Governance**: shadow AI usage, tenant controls, telemetry from licensed platforms

## Challenged-default candidates

Presence identity for every agent vs a few high-touch teammates; suite copilots vs independent assistants in the same tenant. Each track proposes its final list at kickoff.
