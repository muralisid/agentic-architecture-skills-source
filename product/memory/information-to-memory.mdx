## Start with the original

Keep a stable source reference and the evidence that supports a derived fact. For a document, this may be a page and passage. For a video, it is a clip and time interval. For a sensor, it is the readings, units, and observation window.

## Check before adding intelligence

Resolve the asset or customer identity. Check timestamps, permissions, and quality. Separate missing information from a confirmed negative finding. If parsing loses a table heading or unit, a later model may produce a fluent but incorrect interpretation.

## Prepare for a particular task

Use chunks, extracted fields, relationships, or representations where they help a known question. Retain the original evidence alongside summaries or extracted facts so a reader can inspect details that extraction omitted.

## Govern durable memory

Task context is temporary working material. Information retained for future tasks needs an owner, a purpose, a retention decision, and an update path. A proposed lesson from one run is not automatically an approved policy.

## Verify the complete path

Test a question whose answer changed, a record the user cannot access, a deleted source, and a question the evidence cannot answer. The result should respect the source state, not simply return the closest match.
