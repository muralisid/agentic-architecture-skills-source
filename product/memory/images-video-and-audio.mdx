## A description can point to evidence without proving the event

A safety assistant finds a recording labelled “unsafe behavior in the loading bay”. If the whole hour has one summary, the reviewer still has to find the few seconds that support the claim. If the agent retains only that summary, later questions about who was present or what happened just before the event may be impossible to check.

The memory should help someone discover the recording and inspect the relevant interval. These are separate jobs. Keep the observation accessible and treat the generated description as an interpretation to verify.

## Keep an event record

Store the source, observation interval, asset or scene, model version, and uncertainty with a derived event. Preserve the original media reference. A generated description is an interpretation, not a replacement for the recording.

## Choose the model for the job

A detector can locate a known object or event. A vision-language model can help interpret a scene. A speech model can produce a transcript. These outputs may support the same investigation, but they can fail differently.

## Retrieve the useful interval

A whole-video representation may find a related recording without locating the exact second that matters. Evaluate both discovery and event localization. For conversations, retain speaker attribution and timing only to the extent supported by the recording and approved identity process.

## Inspect before acting

For a safety case, show the reviewer the supporting clip and the applicable procedure. Generated coaching media must be clearly separated from incident evidence. Uncertain identification should not trigger a message to an assumed person.

## Test on the environment

Include darkness, occlusion, background noise, unusual equipment, and events that should not be flagged. Compare the complete workflow with the existing detector or manual review process.

The [safety-coaching example](/use-cases/safety-coaching) shows a proposed application. NVIDIA documents a video-search blueprint; Roboflow documents configurable vision workflows. These are vendor-described implementation options, not independent proof of this case’s outcomes.
