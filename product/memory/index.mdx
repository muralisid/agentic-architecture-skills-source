Imagine an agent investigating a pump. It needs the correct asset record, relevant previous work, current readings, and the procedure that applies today. Keeping more text is not enough: the agent must find the right evidence and know what it is allowed to use.

## Start with the question

A record can answer “Which pump is this?” A document search can locate a procedure. A time-series representation may help find similar operating behavior. A graph can help follow relationships. Choose the representation for the question, then test it against a simpler alternative.

## Keep it correct as the world changes

[Changing facts](/memory/changing-facts) covers versions, conflicts, dates, and expiry. [Permissions and lifecycle](/memory/permissions-and-lifecycle) covers access, updates, deletion, and ownership. Remembered information does not become an approved business rule merely because it was repeated.
