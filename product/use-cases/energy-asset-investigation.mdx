Consider equipment at a generation site operating outside its expected temperature range. A dashboard flags the difference. An engineer must still check operating load, sensor quality, recent work, and inspection evidence before deciding whether maintenance is needed. The agent's proposed contribution is to help investigate that difference.

## Establish a trustworthy starting point

Keep the asset identifier, measurement interval, units, operating baseline, and sensor quality with the alert. For a thermal or visual inspection, retain the original image, date, location, and inspection conditions. An apparent hotspot or performance difference is a candidate for review, not a completed diagnosis.

## Ask the next useful question

Is the difference explained by operating conditions? Did it begin after maintenance? Is one measurement unreliable? Use approved analysis tools to compare evidence. Request a targeted inspection only if it can distinguish the remaining explanations. Stop when an engineer can assess the case, evidence remains insufficient, or the investigation limit is reached.

## Combine models through evidence

A time-series model can identify unusual behavior. A vision model can locate a candidate feature in inspection imagery. An LLM can organize their outputs alongside work records and propose the next check. Preserve each tool's uncertainty and source references. Do not treat agreement between models as independent proof when they rely on the same observations.

Memory connects current task progress, similar past cases, and approved engineering procedures. Similarity retrieval suggests useful comparisons; the engineer checks whether the operating conditions make them relevant.

## Prepare a controlled handover

Provide the finding, alternatives considered, supporting sources, unresolved questions, and suggested work scope. The engineering owner approves the response. The agent may create a draft work item through a permitted interface; it does not alter setpoints, isolate equipment, or commit an outage.

## Test whether it earns its place

Compare the agent with existing alarms, fixed checks, and engineer-led investigation. Measure accepted findings, missed issues in reviewed samples, false work requests, review time, investigation cost, and work-package quality. Reduced downtime is a separate outcome requiring a defensible comparison over time.
