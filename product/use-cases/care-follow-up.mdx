Consider an approved follow-up plan involving more than one team. A reminder may be delivered while the actual task remains unfinished. This design keeps the agreed action, its owner, and its completion evidence together.

## Start with an approved task

Record the requested action, responsible team, due date, communication permissions, and expected confirmation. An unclear plan goes back to the care team. The agent must not invent a follow-up action to fill a gap.

## Check what actually happened

Look for the agreed completion record in an authorized system. A message receipt, a scheduled appointment, and a completed encounter describe different states. If a record is missing, ask the responsible team for the specific confirmation rather than repeatedly messaging the patient.

## Use memory to avoid repeated work

Task memory keeps requests, responses, deadlines, and unresolved reasons together. Reference memory holds the approved operating procedure and communication templates. Restrict access by role and purpose, and apply the organization's retention policy to records and derived summaries.

## Stop at the agreed boundary

Set contact limits, escalation deadlines, and a named care coordinator. Route symptoms, uncertainty about urgency, and changes to the plan into the care team's approved process. The agent cannot mark a clinical action complete from a plausible summary alone.

## Compare with the simpler alternative

A reminder queue may be sufficient when every task has the same inputs and completion rule. Test whether the agent improves resolution of variable, multi-team exceptions. Measure unresolved tasks, incorrect closure, unnecessary contacts, coordinator workload, and time to verified completion. Keep adverse events and patient complaints visible separately.

## Standards connection

The [HL7 FHIR R4 Task specification](https://hl7.org/fhir/R4/task.html) represents task status, ownership, inputs, and outputs. It can support the distinction between requested work and completed work. Local workflow design and clinical governance remain necessary. Reviewed 18 September 2026.
