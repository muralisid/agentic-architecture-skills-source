# Synthesis

Cross-layer artifacts produced in Phase 1 (vision, maturity model) and Phase 4 (after layer research). These are the guide's core chapters.

Planned artifacts:

- `vision-and-target-state.md`: the vision essay and target state (Phase 1; outline first)
- `maturity-model.md`: the Autonomy-Learning maturity model (A x L)
- `archetype-grid.md`: the size-by-gravity enterprise archetypes (published)
- `master-target-state.md`: the layered master architecture of the agentic enterprise, including the data pipelines that organize enterprise data into agent memory tiers
- `concerns-by-layers-matrix.md`: 14 tracks by 10 concerns (C1 to C10), rolled up from every track's mandatory section
- `memory-pipeline-architecture.md`: end-to-end workflows and pipelines feeding each memory tier, with governance per tier
- `economics-model.md`: the three pricing regimes, the who-pays-the-loop worksheet, per-task unit-economics method
- `sovereignty-matrix.md`: deployment spectrum and classification-based routing decisions
- `identity-security-model.md`: the Levels 1 to 3 identity taxonomy and the deterministic boundary architecture
- `learning-loops-map.md`: which learning flywheel operates at which layer, and how instance memory promotes into it
