# Code of Conduct

This project follows the spirit of the Contributor Covenant (v2.1).

## Expectations

- Argue about evidence, architecture, and economics; never about people
- Assume good faith; challenge ideas with sources, not status
- No harassment, personal attacks, or discriminatory language
- Disclose conflicts of interest: if you work for a vendor discussed here, say so in your PR or issue

## Enforcement

Report unacceptable behavior by opening an issue mentioning the maintainer (@muralisidfn7) or contacting them via their GitHub profile. The maintainer may edit, remove, or reject contributions and comments that violate this code, and may block repeat offenders.

Full covenant text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
