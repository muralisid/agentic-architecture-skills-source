# Blueprint template

Every blueprint uses this shape. Sections are mandatory; a section with nothing to say says so.

## 1. The scenario

One concrete situation, specific enough that a practitioner recognises it. Not a capability list.

## 2. Agent team design

Which agents, what each does, and where each sits on the A x L grid. Named by function, never by product.

## 3. Planes activated

Which of the seven planes do real work here, marked direct or supporting. A blueprint that activates only the knowledge plane is a demo.

## 4. Controls

The specific controls this scenario requires, drawn from the concerns matrix. Named enforcement points, not principles.

## 5. Economics

Cost per run for control, cost per resolved outcome for the decision, in the currency the function actually manages.

## 6. Honest limits

What does not work here, what has no published precedent, and what the guide refuses to claim. Mandatory. A blueprint without this section has not been researched.

## 7. Metrics

What proves this is working, and what would prove it is not.
